# SAD figures (v1.2)

The new and redrawn figures of `InterviewBuddy_Software_Architecture_Document_v1.2.docx`, drawn with matplotlib in the style of the v1.1 figures.

| File | Figure |
| --- | --- |
| `fig3c_web.png` | Figure 3c. Web Client: voice input, answer feedback and report (Build 2) |
| `fig4b_api.png` | Figure 4b. API Server: answer feedback, report, PDF and practice (Build 2) |
| `fig6b_ai.png` | Figure 6b. AI Integration: answer scoring, report summary and practice questions (Build 2) |
| `fig7_erd.png` | Figure 7. Data view: entity–relationship diagram (Build 2) |
| `fig8_deployment.png` | Figure 8. UML deployment diagram |

To change a figure, edit its script and run it from this folder, for example `py fig_deploy.py fig8_deployment.png`. Then replace the picture in the document. `diag.py` holds the shared drawing helpers (class box, UML node, artifact, arrows).
